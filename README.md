# ReUse — Plataforma de Reutilização

O **ReUse** conecta pessoas para reutilização de itens, reduzindo desperdício e incentivando o consumo consciente.

O projeto é dividido em duas áreas:

- [`mobile/`](mobile/README.md) — aplicativo **React Native (Expo)**
- [`web/`](web/README.md) — área web em **Next.js**

Cada pasta tem seu próprio README com objetivos, telas, stack e instruções de como rodar.
